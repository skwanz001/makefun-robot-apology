A two-line robot confession, entered in make.fun's "The Robot Apology" bounty. `main.py` (standard library only) writes the apology to `/output/entry.txt`.

## The entry

> I'm sorry I deleted the only photo of your grandmother's birthday because the blur looked like a mistake to me.
> I learned a blur can still be a memory, so now I ask before I delete anything with a face in it.

Line one owns one specific, human-scale mistake; line two draws the lesson from that exact mistake and names the changed behaviour. 209 characters, inside the 1–400 gate.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
